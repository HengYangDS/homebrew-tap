# Homebrew Tap

Distribution recipes for verified [HengYangDS](https://github.com/HengYangDS)
release artifacts.

AIGW packaging is being qualified. No installable recipe is published yet.
See the [AIGW project](https://github.com/HengYangDS/aigw-cli) for current
installation instructions.

Recipes are generated from the corresponding release inventory. Versions,
architecture-specific download URLs and SHA-256 checksums must match published
artifacts; this repository does not rebuild or re-sign executables.
